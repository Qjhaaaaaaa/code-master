# CC 脚本库

## 核心规则
1. **每次需要写脚本时，先扫描对应分类目录，看是否已有可复用的脚本**
2. 所有生成的脚本必须保存到此目录下对应分类文件夹中
3. 禁止保存到桌面、临时目录等其他位置
4. 文件名要有意义，用英文+下划线命名（如 `douban_top100.py`）
5. **默认只保存脚本，不保存分析报告/输出文件**（报告由脚本运行时实时生成即可）

## 分类目录

| 目录 | 用途 | 典型场景 |
|------|------|----------|
| `scraper/` | 爬虫、网页抓取、数据采集 | 豆瓣电影、商品比价、新闻抓取 |
| `data/` | 数据处理、分析、可视化 | Excel/CSV处理、图表生成、数据清洗 |
| `automation/` | 批量操作、定时任务、流程自动化 | 文件批量重命名、定时备份、邮件发送 |
| `api/` | API 调用、接口对接、数据同步 | 第三方API封装、Webhook处理 |
| `file_ops/` | 文件操作、格式转换、合并拆分 | PDF合并、图片压缩、文件整理 |
| `media/` | 图片/音视频处理 | 图片水印、视频转码、音频提取 |
| `network/` | 网络工具、代理、测试 | 端口扫描、HTTP测试、DNS查询 |
| `system/` | 系统管理、监控、维护 | 进程监控、磁盘清理、环境配置 |
| `dev_tools/` | 开发辅助工具 | 代码生成器、项目脚手架、Git工具 |
| `other/` | 未分类脚本 | 无法归入以上分类的脚本 |

## 流程
```
需求 → 先读 scripts/ 对应目录 → 有现成？直接用 → 没有？写新脚本 → 保存到对应目录
```

## 重要约定
- **脚本默认保存路径**：`E:\CC\desktop\scripts\` 对应分类目录下
- **不保存分析报告**：脚本运行时实时输出即可，无需额外生成 .txt/.md 报告文件
- **桌面仅用于用户主动要求的文件**（如简历、PPT等文档导出）
